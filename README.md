# Yin Chhaychinh — Modular Portfolio Architecture

This project is a modularized version of Yin Chhaychinh's professional portfolio.

## Directory Structure

- `index.html`: The main entry point.
- `assets/`: Images, documents, and icons.
- `css/`: Modular stylesheets.
- `js/`: Modular JavaScript logic.
- `sections/`: HTML fragments for different portfolio tabs.
- `data/`: JSON data files for content management.

## Setup

To view the portfolio correctly with modular sections loading, please run a local development server (e.g., Live Server in VS Code) to avoid browser CORS restrictions when loading local files via `fetch`.

```bash
# Example using python
python -m http.server
```

## Features

- **Theming**: Integrated Dark/Light mode.
- **Interactivity**: Dynamic tab switching, skill bars, and competency radar charts.
- **Chatbot**: Simulated AI assistant for quick inquiries.
- **Responsive**: Fully optimized for mobile and print.
